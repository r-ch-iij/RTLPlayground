SFP EEPROM Editor

使い方 / Usage
  1. Slot で SFP を選択し、Refresh で EEPROM を読み出します。
  2. hexdump のセルをクリックすると、その1バイトを書き換えられます（Write）。変更後は Fix Checksum でチェックサムを更新してください。
  3. Patch FC->Eth は FC モジュールの EEPROM を Ethernet 用に修正します。
  4. Save Backup で現在の EEPROM をフラッシュに退避、Restore Backup で復元できます。
  5. Download .bin で 256 バイトの EEPROM イメージを保存、Upload .bin で書き込みます。
  6. パスワード保護されたモジュールは PW に 8 桁の HEX パスワードを入力してください。
